# Contributing

Contribute framework code, generic adapters, documentation or a synthetic bug reproduction. Use a clean fork of this repository; never push or merge a research checkout into it.

Run the full tests, public-source smoke and publication validator. A new or changed file needs a reviewed entry in `publication/allowlist.json`; document whether it is framework source, documentation, a synthetic test, configuration example or explicitly public example. Do not approve a hash until the content has been inspected.

Never submit personal strategies, research history, real results, account/position/trade information, credentials, machine paths, logs, grants, bills or runtime databases. Public reports must be intentional, attributed examples. Disclosure of a secret should be reported privately through GitHub's security reporting feature, without copying the secret into an issue.
